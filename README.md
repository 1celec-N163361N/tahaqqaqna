# تحققنا — إصدار الهوية الوطنية لأول مرة عن بُعد

> نموذج تفاعلي (Prototype) لمنصة تحقّق حيوي عن بُعد، يشرح رحلة إصدار الهوية الوطنية
> لأول مرة دون حضور مقدم الطلب إلى مركز الخدمة.

---

## ما هذه المنصة؟

منصة ويب تفاعلية من سبع خطوات تحاكي رحلة كاملة:

| # | الخطوة | ما تعرضه |
|---|--------|----------|
| — | العرض التعريفي | فيديو شرح (٣٤ ثانية) + أبرز مبادئ المنصة |
| ١ | التحقق من مقدم الطلب | رقم الطلب + تحدّي رقمي عشوائي يثبت أن المستخدم إنسان |
| ٢ | اختيار النمط | منفرد أو تابع (أبناء) مع بيانات توضيحية |
| ٣ | الموافقة والاستعداد | موافقة مستنيرة + فحص جاهزية الجهاز والإضاءة |
| ٤ | صورة الهوية | رفع صورة أو التقاطها، مع فحص الجودة والالتزامات الرسمية |
| ٥ | التحقق الحيوي | كاميرا حيّة + تحدّي حركة عشوائي + مساعد تصوير فوري |
| ٦ | تأكيد البيانات | مراجعة الحقول المستخرجة + رمز تحقق (OTP) |
| ٧ | نتيجة التحقق | درجة ثقة مركّبة + أسباب القرار + ما تم إصداره |

بالإضافة إلى **لوحة المراجع البشري**: طابور حالات مع درجة ثقة، أسباب، وزرّي
«موافقة / رفض» موثّقين — للحالات الحدّية والاستثناءات.

## التقنية

- **React 18** + **Vite 5** (بدون أي مكتبة واجهات خارجية — كل المكوّنات مكتوبة يدويًا)
- **CSS** مكتوب من الصفر: نظام تصميم بمتغيّرات، دعم كامل لـ RTL، بلا إطار عمل
- **صفر اعتماديات وقت التشغيل** غير React — لا خطوط محزومة، لا صور خارجية
- خط **IBM Plex Sans Arabic** من Google Fonts

```
src/
├── App.jsx              # الهيكل + حالة الرحلة + روابط العرض العميق
├── data.js              # البيانات التوضيحية (المتقدمون، الحالات، الأسئلة)
├── styles.css           # نظام التصميم الكامل
├── components/
│   ├── Stepper.jsx      # الريل الجانبي + الشعار
│   ├── Header.jsx       # الشريط العلوي + سيناريوهات المحاكاة
│   ├── Intro.jsx        # صفحة العرض التعريفي (الفيديو)
│   ├── Capture.jsx      # مكوّن الكاميرا + مساعد التصوير
│   ├── TrustEngine.jsx  # محرك درجة الثقة
│   ├── ReviewConsole.jsx# لوحة المراجع البشري
│   └── ui.jsx           # أزرار، أيقونات، كروت، مقياس
└── steps/               # الخطوات السبع، كل خطوة في ملف
```

## التشغيل محليًا

```bash
npm install
npm run dev      # http://localhost:5173
```

بناء نسخة الإنتاج:

```bash
npm run build    # الناتج في dist/
npm run preview  # معاينة dist على http://localhost:4173
```

## روابط العرض السريع (للتقييم)

يمكنك القفز مباشرة إلى أي خطوة — مفيد عند العرض أمام اللجنة:

| الرابط | الوجهة |
|--------|--------|
| `/` | العرض التعريفي (الفيديو) |
| `/?step=1` … `/?step=7` | الخطوة المطلوبة، مع تعبئة البيانات تلقائيًا |
| `/?view=review` | لوحة المراجع البشري |

مثال: `https://<نطاقك>/?step=5` يفتح خطوة التحقق الحيوي مباشرة.

## النشر

التفاصيل الكاملة في **[DEPLOY.md](./DEPLOY.md)** — الخلاصة:

1. اربط المستودع على [CranL](https://cranl.com) واختر الفرع `main`.
2. CranL يكتشف **Vite** تلقائيًا: أمر البناء `npm run build`، مجلد الناتج `dist`.
3. اضغط Deploy — وستحصل على رابط `https://<app>.cranl.net` مع HTTPS.

لا حاجة لأي متغيّرات بيئة، ولا قاعدة بيانات، ولا خادم خلفي — الموقع ساكن بالكامل.
